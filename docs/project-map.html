Inventory Audit Dashboard · Project Map

Where everything lives, what it's built with, and where to go to change things.

1. How it's built

Framework

React 19 single-page app (JSX, no TypeScript), bundled by Vite 8.

Routing

React Router 7. All routes are declared at the bottom of src/App.jsx.

Styling

Tailwind CSS 3 utility classes (+ tailwindcss-animate). Not custom CSS — see section 4.

UI kit

shadcn/ui-style components (new-york style) on Radix UI primitives, icons from lucide-react.

Tables

TanStack Table v8 (data-table.jsx).

Excel

ExcelJS writes exports; xlsx (SheetJS) reads uploaded inventory files.

Data storage

No backend or database. State is saved in the browser's localStorage (key inventory-audit-react-state).

Hosting

Cloudflare static assets: npm run build → dist/, deployed with Wrangler (wrangler.jsonc, SPA fallback).

Commands: npm install · npm run dev (local server) · npm run build · npm run preview · tests: node --test tests/

4. Tailwind or custom CSS?

Tailwind Almost all styling is Tailwind utility classes written directly in the JSX (e.g. className="rounded-xl border p-4"). The only stylesheet the app loads is src/index.css: Tailwind's layers plus the theme palettes (default, tokyo-night, github-white, nord, emerald, sandstone, mist), each a set of CSS variables. tailwind.config.js maps slate, sky, white and the semantic colors to those variables, so switching theme in Settings recolors everything. To add a theme: add an html[data-theme="…"] block in index.css and register it in themes in src/lib/utils.js.

Not used The root style.css is leftover custom CSS from the earlier version and isn't imported by the app.

5. How the pieces connect

index.html→main.jsx→App.jsx (state + routes)→components/*→lib/* (logic, Excel)

App.jsx holds one shared state (inventory, audits, locations, notes…) and an update() function, passed to every screen. Changes are saved to localStorage automatically. Screens call helpers in lib/ for calculations and Excel import/export. The calendar schedule and a few preferences are stored in their own localStorage keys.
